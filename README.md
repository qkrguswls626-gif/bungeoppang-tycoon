# 붕어빵 타이쿤

옛날 피처폰 감성의 도트 붕어빵 장사 웹게임입니다. `index.html` 하나로 동작하며, 외부 라이브러리나 이미지 파일을 쓰지 않습니다.

## 실행
`index.html`을 브라우저로 열면 됩니다.

## 조작
| 동작 | PC | 모바일 |
| --- | --- | --- |
| 틀 1~9 누르기 | 숫자키 `1`~`9` | 틀 또는 키패드 버튼 터치 |
| 속 바꾸기 (팥 ↔ 슈크림) | `0` / `Space` / `*` | 하단 `0:팥` 버튼 |
| 상점 구매 / 다음 날 | `1`~`4` / `0`, `Enter` | 항목 / 노란 버튼 터치 |
| 소리 켜기/끄기 | `M` | - |

## 규칙
- 칸을 누를 때마다 **반죽 → 속넣기 → 뒤집기 → 꺼내기**
- 칸 아래 막대의 흰 표시가 초록 구간이면 잘 익은 것. 앞면·뒷면 모두 잘 익어야 판매 가능
- 빨간 끝까지 가면 타버리고, 탄 건 한 번 더 눌러 버립니다
- 잘 익은 붕어빵은 진열대에 쌓이고, 손님 주문만큼 자동으로 판매됩니다 (빨리 끝내면 팁)
- 하루 60초, 끝나면 정산 → 상점(불 세기, 틀 추가, 슈크림 맛)
- 날이 갈수록 손님이 빨리 오고 인내심이 줄어듭니다
- 진행 상황은 브라우저 `localStorage`에 저장됩니다
